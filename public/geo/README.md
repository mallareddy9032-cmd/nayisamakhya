# Telangana district boundaries

`telangana-districts.topo.json` — TopoJSON of 33 Telangana districts.

- Source: [udit-001/india-maps-data](https://github.com/udit-001/india-maps-data) (`topojson/states/telangana.json`)
- Augmented with `properties.slug` matching NayiSamakhya portal district slugs
  (Warangal Urban → `hanumakonda`, Warangal Rural → `warangal`, Komaram Bheem → `kumuram-bheem-asifabad`, etc.)
